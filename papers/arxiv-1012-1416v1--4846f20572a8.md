Cross-Domain Object Matching with Model Selection

 

Makoto Yamada          Masashi Sugiyama

Tokyo Institute of Technology yamada@sg.cs.titech.ac.jp          Tokyo
Institute of Technology sugi@cs.titech.ac.jp

###### Abstract

The goal of _cross-domain object matching_ (CDOM) is to find
correspondence between two sets of objects in different domains in an
unsupervised way. Photo album summarization is a typical application of
CDOM, where photos are automatically aligned into a designed frame
expressed in the Cartesian coordinate system. CDOM is usually formulated
as finding a mapping from objects in one domain (photos) to objects in
the other domain (frame) so that the pairwise dependency is maximized. A
state-of-the-art CDOM method employs a kernel-based dependency measure,
but it has a drawback that the kernel parameter needs to be determined
manually. In this paper, we propose alternative CDOM methods that can
naturally address the model selection problem. Through experiments on
image matching, unpaired voice conversion, and photo album summarization
tasks, the effectiveness of the proposed methods is demonstrated.

## 1 Introduction

The objective of _cross-domain object matching_ (CDOM) is to match two
sets of objects in different domains. For instance, in photo album
summarization, photos are automatically assigned into a designed frame
expressed in the Cartesian coordinate system. A typical approach of CDOM
is to find a mapping from objects in one domain (photos) to objects in
the other domain (frame) so that the pairwise dependency is maximized.
In this scenario, accurately evaluating the dependence between objects
is a key challenge.

_Kernelized sorting_ (KS) ([Jebara, 2004](#bib.bib9)) tries to find a
mapping between two domains that maximizes the _mutual information_ (MI)
([Cover and Thomas, 2006](#bib.bib1)) under the Gaussian assumption.
However, since the Gaussian assumption may not be fulfilled in practice,
this method (which we refer to as KS-MI) tends to perform poorly.

To overcome the limitation of KS-MI, [Quadrianto et al.
(2010)](#bib.bib16) proposed using the kernel-based dependence measure
called the _Hilbert-Schmidt independence criterion_ (HSIC) ([Gretton
et al., 2005](#bib.bib5)) for KS. Since HSIC is distribution-free, KS
with HSIC (which we refer to as KS-HSIC) is more flexible than KS-MI.
However, HSIC includes a tuning parameter (more specifically, the
Gaussian kernel width), and its choice is crucial to obtain better
performance ([Jagarlamudi et al., 2010](#bib.bib8), see also). Although
using the median distance between sample points as the Gaussian kernel
width is a common heuristic in kernel-based dependence measures
([Fukumizu et al., 2009a](#bib.bib3), see e.g.,), this does not always
perform well in practice.

In this paper, we propose two alternative CDOM methods that can
naturally address the model selection problem. The first method employs
another kernel-based dependence measure based on the _normalized
cross-covariance operator_ (NOCCO) ([Fukumizu et al.,
2009b](#bib.bib4)), which we refer to as KS-NOCCO. The NOCCO-based
dependence measure was shown to be asymptotically independent of the
choice of kernels. Thus, KS-NOCCO is expected to be less sensitive to
the kernel parameter choice, which is an advantage over HSIC.

The second method uses _least-squares mutual information_ (LSMI)
([Suzuki et al., 2009](#bib.bib19)) as the dependence measure, which is
a consistent estimator of the _squared-loss mutual information_ (SMI)
achieving the optimal convergence rate. We call this method
_least-squares object matching_ (LSOM). An advantage of LSOM is that
cross-validation (CV) with respect to the LSMI criterion is possible.
Thus, all the tuning parameters such as the Gaussian kernel width and
the regularization parameter can be objectively determined by CV.

Through experiments on image matching, unpaired voice conversion, and
photo album summarization tasks, LSOM is shown to be the most promising
approach to CDOM.

## 2 Problem Formulation

In this section, we formulate the problem of _cross-domain object
matching_ (CDOM).

The goal of CDOM is, given two sets of samples of the same size,
$`\{{\bm{x}}_{i}\}_{i=1}^{n}`$ and $`\{{\bm{y}}_{i}\}_{i=1}^{n}`$, to
find a mapping that well “matches” them.

Let $`\pi`$ be a permutation function over $`\{1,\ldots,n\}`$, and let
$`{\bm{\Pi}}`$ be the corresponding permutation indicator matrix, i.e.,

|     |                                                                                                                                                              |     |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | --- |
|     | $`\displaystyle{\bm{\Pi}}\in\{0,1\}^{n\times n},~{\bm{\Pi}}{{\bm{1}}}_{n}={{\bm{1}}}_{n},~\textnormal{and}~{\bm{\Pi}}^{\top}{{\bm{1}}}_{n}={{\bm{1}}}_{n},`$ |     |

where $`{{\bm{1}}}_{n}`$ is the $`n`$-dimensional vector with all ones
and ^(⊤) denotes the transpose. Let us denote the samples matched by a
permutation $`\pi`$ by

|     |     |     |
| --- | --- | --- |
|     |

       ``` math
       Z({\bm{\Pi}}):=\{({\bm{x}}_{i},{\bm{y}}_{\pi(i)})\}_{i=1}^{n}.
       ```                                                             |     |

The optimal permutation, denoted by $`{\bm{\Pi}}^{\ast}`$, can be
obtained as the maximizer of the dependency between the two sets
$`\{{\bm{x}}_{i}\}_{i=1}^{n}`$ and $`\{{\bm{y}}_{i}\}_{i=1}^{n}`$:

|     |                                                                                       |     |
| --- | ------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle{\bm{\Pi}}^{*}:=\mathop{\text{argmax}}_{{\bm{\Pi}}}D(Z({\bm{\Pi}})),`$ |     |

where $`D`$ is some dependence measure.

## 3 Existing Methods

In this section, we review two existing methods for CDOM, and point out
their weaknesses.

### 3.1 Kernelized Sorting with Mutual Information

_Kernelized sorting with mutual information_ (KS-MI) ([Jebara,
2004](#bib.bib9)) matches objects in different domains so that MI
between matched pairs is maximized. Here, we review KS-MI following
alternative derivation provided in [Quadrianto et al.
(2010)](#bib.bib16).

MI is one of the popular dependence measures between random variables.
For random variables $`X`$ and $`Y`$, MI is defined as follows ([Cover
and Thomas, 2006](#bib.bib1)):

|     |     |     |
| --- | --- | --- |
|     |

````math
\mathrm{MI}(Z):=\int p(X,Y)\log\frac{p(X,Y)}{p(X)p(Y)}\mathrm{d}X\mathrm{d}Y,
``` |  |

where $`p(X,Y)`$ denotes the joint density of $`X`$ and $`Y`$, and
$`p(X)`$ and $`p(Y)`$ are marginal densities of $`X`$ and $`Y`$,
respectively. MI is zero if and only if $`X`$ and $`Y`$ are independent,
and thus it may be used as a dependency measure. Let $`H(X)`$, $`H(Y)`$,
and $`H(X,Y)`$ be the entropies of $`X`$ and $`Y`$ and the joint entropy
of $`X`$ and $`Y`$, respectively:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle H(X)`$ | $`\displaystyle=-\int p(X)\log p(X)\mathrm{d}X,`$ |  |
|  | $`\displaystyle H(Y)`$ | $`\displaystyle=-\int p(Y)\log p(Y)\mathrm{d}Y,`$ |  |
|  | $`\displaystyle H(X,Y)`$ | $`\displaystyle=-\int p(X,Y)\log p(X,Y)\mathrm{d}X\mathrm{d}Y,`$ |  |

respectively. Then the mutual information between $`X`$ and $`Y`$ can be
written as

|     |                                 |                                     |     |
|-----|---------------------------------|-------------------------------------|-----|
|     | $`\displaystyle\mathrm{MI}(Z)`$ | $`\displaystyle=H(X)+H(Y)-H(X,Y).`$ |     |

Since $`H(X)`$ and $`H(Y)`$ are independent of permutation
$`{\bm{\Pi}}`$, maximizing mutual information is equivalent to
minimizing the joint entropy $`H(X,Y)`$. If $`p(X,Y)`$ is Gaussian with
covariance matrix $`{\bm{\Sigma}}`$, the joint entropy is expressed as

|     |                                                           |     |
|-----|-----------------------------------------------------------|-----|
|     |
       ``` math
       H(X,Y)=\frac{1}{2}\log|{\bm{\Sigma}}|+\textnormal{Const},
       ```                                                        |     |

where $`|{\bm{\Sigma}}|`$ denotes the determinant of matrix
$`{\bm{\Sigma}}`$.

Now, let us assume that $`{\bm{x}}`$ and $`{\bm{y}}`$ are jointly normal
in some reproducing Kernel Hilbert Spaces (RKHSs) endowed with joint
kernel $`K({\bm{x}},{\bm{x}}^{\prime})L({\bm{y}},{\bm{y}}^{\prime})`$,
where $`K({\bm{x}},{\bm{x}}^{\prime})`$ and
$`L({\bm{y}},{\bm{y}}^{\prime})`$ are reproducing kernels for
$`{\bm{x}}`$ and $`{\bm{y}}`$, respectively. Then KS-MI is formulated as
follows:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\min_{{\bm{\Pi}}}\log|{\bm{\Gamma}}({\bm{K}}\circ({\bm{\Pi}}^{\top}{\bm{L}}{\bm{\Pi}})){\bm{\Gamma}}|,`$ |  | (1) |

where $`{\bm{K}}=\{K({\bm{x}}_{i},{\bm{x}}_{j})\}_{i,j=1}^{n}`$ and
$`{\bm{L}}=\{L({\bm{y}}_{i},{\bm{y}}_{j})\}_{i,j=1}^{n}`$ are kernel
matrices, $`\circ`$ denotes the Hadamard product (a.k.a. the
element-wise product),
$`{\bm{\Gamma}}={\bm{I}}_{n}-\frac{1}{n}{{\bm{1}}}_{n}{{\bm{1}}}_{n}^{\top}`$
is the centering matrix, and $`{\bm{I}}_{n}`$ is the $`n`$-dimensional
identity matrix.

A critical weakness of KS-MI is the Gaussian assumption, which may not
be fulfilled in practice.

### 3.2 Kernelized Sorting with Hilbert-Schmidt Independence Criterion

*Kernelized sorting with Hilbert-Schmidt independence criterion*
(KS-HSIC) matches objects in different domains so that HSIC between
matched pairs is maximized.

HSIC is a kernel-based dependence measure given as follows ([Gretton
et al., 2005](#bib.bib5)):

|  |  |  |
|----|----|----|
|  |
``` math
{\textnormal{HSIC}}(Z)=\textnormal{tr}(\bar{{\bm{K}}}\bar{{\bm{L}}}),
``` |  |

where $`\bar{{\bm{K}}}={\bm{\Gamma}}{\bm{K}}{\bm{\Gamma}}`$ and
$`\bar{{\bm{L}}}={\bm{\Gamma}}{\bm{L}}{\bm{\Gamma}}`$ are the centered
kernel matrices for $`{\bm{x}}`$ and $`{\bm{y}}`$, respectively. Note
that smaller HSIC scores mean that $`X`$ and $`Y`$ are closer to be
independent.

KS-HSIC is formulated as follows ([Quadrianto et al.,
2010](#bib.bib16)):

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\max_{{\bm{\Pi}}}{\textnormal{HSIC}}(Z({\bm{\Pi}})),`$ |  | (2) |

where

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle{\textnormal{HSIC}}(Z({\bm{\Pi}}))=\textnormal{tr}(\bar{{\bm{K}}}{\bm{\Pi}}^{\top}\bar{{\bm{L}}}{\bm{\Pi}}).`$ |  | (3) |

This optimization problem is called the *quadratic assignment problem*
(QAP) ([Finke et al., 1987](#bib.bib2)), and it is known to be
*NP-hard*. There exists several QAP solvers such as methods based on
simulated annealing, tabu search, and genetic algorithms. However, those
QAP solvers are not easy to use in practice since they contain various
tuning parameters.

Another approach to solving
Eq.([2](#S3.E2 "In 3.2 Kernelized Sorting with Hilbert-Schmidt Independence Criterion ‣ 3 Existing Methods"))
based on a *linear assignment problem* (LAP) ([Kuhn, 1955](#bib.bib11))
was proposed in [Quadrianto et al. (2010)](#bib.bib16), which is
explained below. Let us relax the permutation indicator matrix
$`{\bm{\Pi}}`$ to take real values:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle{\bm{\Pi}}\in[0,1]^{n\times n},~{\bm{\Pi}}{{\bm{1}}}_{n}={{\bm{1}}}_{n},~\textnormal{and}~{\bm{\Pi}}^{\top}{{\bm{1}}}_{n}={{\bm{1}}}_{n}.`$ |  | (4) |

Then,
Eq.([3](#S3.E3 "In 3.2 Kernelized Sorting with Hilbert-Schmidt Independence Criterion ‣ 3 Existing Methods"))
is convex with respect to $`{\bm{\Pi}}`$ ([Quadrianto et al.,
2010](#bib.bib16), see Lemma 7 in), and its lower bound can be obtained
using some $`\widetilde{{\bm{\Pi}}}`$ as follows:

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\textnormal{tr}(\bar{{\bm{K}}}{\bm{\Pi}}^{\top}\bar{{\bm{L}}}{\bm{\Pi}})`$ |  |
|  |  | $`\displaystyle\geq\textnormal{tr}(\bar{{\bm{K}}}\widetilde{{\bm{\Pi}}}^{\top}\bar{{\bm{L}}}\widetilde{{\bm{\Pi}}})+\langle{\bm{\Pi}}-\widetilde{{\bm{\Pi}}},\frac{\partial{\textnormal{HSIC}}(Z(\widetilde{{\bm{\Pi}}}))}{\partial{\bm{\Pi}}}\rangle`$ |  |
|  |  | $`\displaystyle=2\textnormal{tr}(\bar{{\bm{K}}}{\bm{\Pi}}^{\top}\bar{{\bm{L}}}\widetilde{{\bm{\Pi}}})-\textnormal{tr}(\bar{{\bm{K}}}\widetilde{{\bm{\Pi}}}^{\top}\bar{{\bm{L}}}\widetilde{{\bm{\Pi}}}),`$ |  |

where $`\langle\cdot,\cdot\rangle`$ denotes the inner product between
matrices. Based on the above lower bound, [Quadrianto et al.
(2010)](#bib.bib16) proposed to update the permutation matrix as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle{\bm{\Pi}}^{\textnormal{new}}=(1-\eta){\bm{\Pi}}^{\textnormal{old}}+\eta\mathop{\text{argmax}}_{{\bm{\Pi}}}\textnormal{tr}\left({\bm{\Pi}}^{\top}\bar{{\bm{L}}}{\bm{\Pi}}^{\textnormal{old}}\bar{{\bm{K}}}\right),`$ |  | (5) |

where $`0<\eta\leq 1`$ is a step size. The second term is an LAP
subproblem, which can be efficiently solved by using the *Hungarian
method*.

In the original KS-HSIC paper ([Quadrianto et al., 2010](#bib.bib16)), a
C++ implementation of the Hungarian method provided by Cooper¹¹ 1
http://mit.edu/harold/www/code.html was used for solving
Eq.([5](#S3.E5 "In 3.2 Kernelized Sorting with Hilbert-Schmidt Independence Criterion ‣ 3 Existing Methods"));
then $`{\bm{\Pi}}`$ is kept updated by
Eq.([5](#S3.E5 "In 3.2 Kernelized Sorting with Hilbert-Schmidt Independence Criterion ‣ 3 Existing Methods"))
until convergence.

In this iterative optimization procedure, the choice of initial
permutation matrices is critical to obtain a good solution. [Quadrianto
et al. (2010)](#bib.bib16) proposed the following initialization scheme.
Suppose the kernel matrices $`\bar{{\bm{K}}}`$ and $`\bar{{\bm{L}}}`$
are rank one, i.e., for some $`{\bm{f}}`$ and $`{\bm{g}}`$,
$`\bar{{\bm{K}}}`$ and $`\bar{{\bm{L}}}`$ can be expressed as
$`\bar{{\bm{K}}}={\bm{f}}{\bm{f}}^{\top}`$ and
$`\bar{{\bm{L}}}={\bm{g}}{\bm{g}}^{\top}`$. Then HSIC can be written as

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle{\textnormal{HSIC}}(Z({\bm{\Pi}}))`$ | $`\displaystyle=\|{\bm{f}}^{\top}{\bm{\Pi}}{\bm{g}}\|^{2}.`$ |  | (6) |

The initial permutation matrix is determined so that
Eq.([6](#S3.E6 "In 3.2 Kernelized Sorting with Hilbert-Schmidt Independence Criterion ‣ 3 Existing Methods"))
is maximized. According to Theorems 368 and 369 in [Hardy et al.
(1952)](#bib.bib6), the maximum of
Eq.([6](#S3.E6 "In 3.2 Kernelized Sorting with Hilbert-Schmidt Independence Criterion ‣ 3 Existing Methods"))
is attained when the elements of $`{\bm{f}}`$ and $`{\bm{\Pi}}{\bm{g}}`$
are ordered in the same way. That is, if the elements of $`{\bm{f}}`$
are ordered in the ascending manner (i.e.,
$`f_{1}\leq f_{2}\leq\cdots\leq f_{n}`$), the maximum of
Eq.([6](#S3.E6 "In 3.2 Kernelized Sorting with Hilbert-Schmidt Independence Criterion ‣ 3 Existing Methods"))
is attained by ordering the elements of $`{\bm{g}}`$ in the same
ascending way. However, since the kernel matrices $`\bar{{\bm{K}}}`$ and
$`\bar{{\bm{L}}}`$ may not be rank one in practice, the principal
eigenvectors of $`\bar{{\bm{K}}}`$ and $`\bar{{\bm{L}}}`$ were used as
$`{\bm{f}}`$ and $`{\bm{g}}`$ in the original KS-HSIC paper ([Quadrianto
et al., 2010](#bib.bib16)). We call this *eigenvalue-based
initialization*.

Since HSIC is a distribution-free dependence measure, KS-HSIC is more
flexible than KS-MI. However, a critical weakness of HSIC is that its
performance is sensitive to the choice of kernels ([Jagarlamudi et al.,
2010](#bib.bib8)). A practical heuristic is to use the Gaussian kernel
with width set to the median distance between samples ([Fukumizu et al.,
2009a](#bib.bib3), see e.g.,), but this does not always work well in
practice.

## 4 Proposed Methods

In this section, we propose two alternative CDOM methods that can
naturally address the model selection problem.

### 4.1 Kernelized Sorting with Normalized Cross-Covariance Operator

The kernel-based dependence measure based on the *normalized
cross-covariance operator* (NOCCO) ([Fukumizu et al., 2009b](#bib.bib4))
is given as follows ([Fukumizu et al., 2009b](#bib.bib4)):

|  |  |  |
|----|----|----|
|  |
``` math
\textnormal{D}_{\textnormal{NOCCO}}(Z)=\textnormal{tr}(\widetilde{{\bm{K}}}\widetilde{{\bm{L}}}),
``` |  |

where
$`\widetilde{{\bm{K}}}=\bar{{\bm{K}}}(\bar{{\bm{K}}}+n\epsilon{\bm{I}}_{n})^{-1}`$,
$`\widetilde{{\bm{L}}}=\bar{{\bm{L}}}(\bar{{\bm{L}}}+n\epsilon{\bm{I}}_{n})^{-1}`$,
and $`\epsilon>0`$ is a regularization parameter.
$`\textnormal{D}_{\textnormal{NOCCO}}`$ was shown to be asymptotically
independent of the choice of kernels. Thus, KS with
$`\textnormal{D}_{\textnormal{NOCCO}}`$ (KS-NOCCO) is expected to be
less sensitive to the kernel parameter choice than KS-HSIC.

The permuted version of $`\widetilde{{\bm{L}}}`$ can be written as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\widetilde{{\bm{L}}}({\bm{\Pi}})`$ | $`\displaystyle={\bm{\Pi}}^{\top}\bar{{\bm{L}}}{\bm{\Pi}}({\bm{\Pi}}^{\top}\bar{{\bm{L}}}{\bm{\Pi}}+n\epsilon{\bm{I}}_{n})^{-1}`$ |  |
|  |  | $`\displaystyle={\bm{\Pi}}^{\top}\bar{{\bm{L}}}(\bar{{\bm{L}}}+n\epsilon{\bm{I}}_{n})^{-1}{\bm{\Pi}}`$ |  |
|  |  | $`\displaystyle={\bm{\Pi}}^{\top}\widetilde{{\bm{L}}}{\bm{\Pi}},`$ |  |

where we used the orthogonality of $`{\bm{\Pi}}`$ (i.e.,
$`{\bm{\Pi}}^{\top}{\bm{\Pi}}={\bm{\Pi}}{\bm{\Pi}}^{\top}={\bm{I}}_{n}`$).
Thus, the dependency measure for $`Z({\bm{\Pi}})`$ can be written as

|  |  |  |
|----|----|----|
|  | $`\displaystyle\textnormal{D}_{\textnormal{NOCCO}}(Z({\bm{\Pi}}))=\textnormal{tr}(\widetilde{{\bm{K}}}{\bm{\Pi}}^{\top}\widetilde{{\bm{L}}}{\bm{\Pi}}).`$ |  |

Since this is essentially the same form as HSIC, a local optimal
solution may be obtained in the same way as KS-HSIC:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle{\bm{\Pi}}^{\textnormal{new}}=(1-\eta){\bm{\Pi}}^{\textnormal{old}}+\eta\mathop{\text{argmax}}_{{\bm{\Pi}}}\textnormal{tr}\left({\bm{\Pi}}^{\top}\widetilde{{\bm{L}}}{\bm{\Pi}}^{\textnormal{old}}\widetilde{{\bm{K}}}\right).`$ |  | (7) |

However, the property that $`\textnormal{D}_{\textnormal{NOCCO}}`$ is
independent of the kernel choice holds only asymptotically. Thus, with
finite samples, $`\textnormal{D}_{\textnormal{NOCCO}}`$ does depend on
the choice of kernels as well as the regularization parameter
$`\epsilon`$ which needs to be manually tuned.

### 4.2 Least-Squares Object Matching

Next, we propose an alternative method called *least-squares object
matching* (LSOM), in which we employ *least-squares mutual information*
(LSMI) ([Suzuki et al., 2009](#bib.bib19)) as a dependency measure. LSMI
is a consistent estimator of the *squared-loss mutual information* (SMI)
achieving the optimal convergence rate. SMI is defined and expressed as

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\textnormal{SMI}(Z)`$ |  |  |
|  |  | $`\displaystyle=\frac{1}{2}\int\int\left(\frac{p(X,Y)}{p(X)p(Y)}-1\right)^{2}p(X)p(Y)\textnormal{d}X\textnormal{d}Y`$ |  |  |
|  |  | $`\displaystyle=\frac{1}{2}\iint\left(\frac{p(X,Y)}{p(X)p(Y)}\right)p(X,Y)\textnormal{d}X\textnormal{d}Y-\frac{1}{2}.`$ |  | (8) |

Note that SMI is the *Pearson divergence* ([Pearson, 1900](#bib.bib14))
from $`p(X,Y)`$ to $`p(X)p(Y)`$, while ordinary MI is the
*Kullback-Leibler divergence* ([Kullback and Leibler, 1951](#bib.bib12))
from $`p(X,Y)`$ to $`p(X)p(Y)`$. SMI is zero if and only if $`X`$ and
$`Y`$ are independent, as ordinary MI. Its estimator LSMI is given as
follows ([Suzuki et al., 2009](#bib.bib19)):

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathrm{LSMI}(Z)`$ | $`\displaystyle=\frac{1}{2}{{\bm{\alpha}}}^{\top}{{\bm{h}}}-\frac{1}{2},`$ |  |

where

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle{{\bm{\alpha}}}`$ | $`\displaystyle={\bm{H}}^{-1}{\bm{h}},`$ |  |
|  | $`\displaystyle{\bm{H}}`$ | $`\displaystyle=\frac{1}{n^{2}}\left(({\bm{K}}{\bm{K}}^{\top})\circ({\bm{L}}{\bm{L}}^{\top})+\lambda{\bm{I}}_{n}\right),`$ |  |
|  | $`\displaystyle{{\bm{h}}}`$ | $`\displaystyle=\left(\frac{1}{n}{\bm{K}}\circ{\bm{L}}\right){{\bm{1}}}_{n}.`$ |  |

Here, $`\lambda`$ ($`\geq 0`$) is the regularization parameter. Since
cross-validation (CV) with respect to SMI is possible for model
selection, tuning parameters in LSMI (i.e., the Gaussian kernel width
and the regularization parameter) can be objectively optimized. This is
a notable advantage over kernel-based approaches.

Below, we use the following equivalent expression of LSMI:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle{\textnormal{LSMI}}(Z)`$ | $`\displaystyle=\frac{1}{2n}\textnormal{tr}\left({\bm{L}}{{\bm{A}}}{\bm{K}}\right)-\frac{1}{2},`$ |  | (9) |

where $`{{\bm{A}}}`$ is the diagonal matrix with diagonal elements given
by $`{\bm{\alpha}}`$. Note that we used Eq.(73) and Eq.(75) in [Minka
(2000)](#bib.bib13) for obtaining the above expression.

LSMI for the permuted data $`Z({\bm{\Pi}})`$ is given by

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathrm{LSMI}(Z({\bm{\Pi}}))`$ | $`\displaystyle=\frac{1}{2n}\textnormal{tr}\left({\bm{\Pi}}^{\top}{\bm{L}}{\bm{\Pi}}{\bm{A}}_{\bm{\Pi}}{\bm{K}}\right)-\frac{1}{2},`$ |  |

where $`{\bm{A}}_{\bm{\Pi}}`$ is the diagonal matrix with diagonal
elements given by $`{\bm{\alpha}}_{\bm{\Pi}}`$, and
$`{\bm{\alpha}}_{\bm{\Pi}}`$ is given by

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle{{\bm{\alpha}}}_{\bm{\Pi}}`$ | $`\displaystyle={\bm{H}}_{\bm{\Pi}}^{-1}{\bm{h}}_{\bm{\Pi}},`$ |  |
|  | $`\displaystyle{\bm{H}}_{\bm{\Pi}}`$ | $`\displaystyle=\frac{1}{n^{2}}\left(({\bm{K}}{\bm{K}}^{\top})\circ({\bm{\Pi}}^{\top}{\bm{L}}{\bm{L}}^{\top}{\bm{\Pi}})+\lambda{\bm{I}}_{n}\right),`$ |  |
|  | $`\displaystyle{{\bm{h}}}_{\bm{\Pi}}`$ | $`\displaystyle=\left(\frac{1}{n}{\bm{K}}\circ({\bm{\Pi}}^{\top}{\bm{L}}{\bm{\Pi}})\right){{\bm{1}}}_{n}.`$ |  |

Consequently, LSOM is formulated as follows:

|     |                                                                  |     |
|-----|------------------------------------------------------------------|-----|
|     | $`\displaystyle\max_{{\bm{\Pi}}}~\mathrm{LSMI}(Z({\bm{\Pi}})).`$ |     |

Since this optimization problem is in general NP-hard and is not convex,
we simply use the same optimization strategy as KS-HSIC, i.e., for the
current $`{\bm{\Pi}}^{\textnormal{old}}`$, the solution is updated as

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle{\bm{\Pi}}^{\textnormal{new}}`$ | $`\displaystyle=(1-\eta){\bm{\Pi}}^{\textnormal{old}}+\eta\mathop{\text{argmax}}_{{\bm{\Pi}}}~\textnormal{tr}\left({\bm{\Pi}}^{\top}{\bm{L}}{\bm{\Pi}}^{\textnormal{old}}{\bm{A}}_{{\bm{\Pi}}^{\textnormal{old}}}{\bm{K}}\right).`$ |  | (10) |

## 5 Experiments

In this section, we first illustrate the behavior of the proposed
methods using a toy data set, and then experimentally evaluate our
proposed algorithms in the image matching, unpaired voice conversion,
and photo album summarization tasks.

In all the methods, we use the Gaussian kernels:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle K({\bm{x}},{\bm{x}}^{\prime})`$ | $`\displaystyle=\exp\left(-\frac{\|{\bm{x}}-{\bm{x}}^{\prime}\|^{2}}{2\sigma_{\mathrm{x}}^{2}}\right),`$ |  |
|  | $`\displaystyle L({\bm{y}},{\bm{y}}^{\prime})`$ | $`\displaystyle=\exp\left(-\frac{\|{\bm{y}}-{\bm{y}}^{\prime}\|^{2}}{2\sigma_{\mathrm{y}}^{2}}\right),`$ |  |

and we set the maximum number of iterations for updating permutation
matrices to 20 and the step size $`\eta`$ to 1. To avoid falling into
undesirable local optima, optimization is carried out 10 times with
different initial permutation matrices, which are determined by the
eigenvalue-based initialization heuristic with Gaussian kernel widths

|  |  |  |
|----|----|----|
|  | $`\displaystyle(\sigma_{\mathrm{x}},\sigma_{\mathrm{y}})=c\times(m_{\mathrm{x}},m_{\mathrm{y}}),`$ |  |

where $`c=1^{1/2},2^{1/2},\ldots,10^{1/2}`$, and

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle m_{\mathrm{x}}`$ | $`\displaystyle=2^{-1/2}\textnormal{median}(\{\|{\bm{x}}_{i}-{\bm{x}}_{j}\|\}_{i,j=1}^{n}),`$ |  |
|  | $`\displaystyle m_{\mathrm{y}}`$ | $`\displaystyle=2^{-1/2}\textnormal{median}(\{\|{\bm{y}}_{i}-{\bm{y}}_{j}\|\}_{i,j=1}^{n}).`$ |  |

In KS-HSIC and KS-NOCCO, we use the Gaussian kernel with the following
widths:

|  |  |  |
|----|----|----|
|  | $`\displaystyle(\sigma_{\mathrm{x}},\sigma_{\mathrm{y}})=c^{\prime}\times(m_{\mathrm{x}},m_{\mathrm{y}}),`$ |  |

where $`c^{\prime}=1^{1/2},10^{1/2}`$. In KS-NOCCO, we use the following
regularization parameters:

|     |                                      |     |
|-----|--------------------------------------|-----|
|     | $`\displaystyle\epsilon=0.01,0.05.`$ |     |

In LSOM, we choose the model parameters of LSMI,
$`\sigma_{\mathrm{x}}`$, $`\sigma_{\mathrm{y}}`$, and $`\lambda`$ by
2-fold CV from

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle(\sigma_{\mathrm{x}},\sigma_{\mathrm{y}})`$ | $`\displaystyle=c\times(m_{\mathrm{x}},m_{\mathrm{y}}),`$ |  |
|  | $`\displaystyle\lambda`$ | $`\displaystyle=10^{-1},10^{-2},10^{-3}.`$ |  |

### 5.3 Unpaired Voice Conversion

Next, we consider an unpaired voice conversion task, which is aimed at
matching the voice of a source speaker with that of a target speaker.

In this experiment, we use 200 short utterance samples recorded from two
male speakers in French, with sampling rate 44.1kHz. We first convert
the utterance samples to 50-dimensional *line spectral frequencies*
(LSF) vector ([Kain and Macon, 1988](#bib.bib10)). We denote the source
and target LSF vectors by $`{\bm{x}}`$ and $`{\bm{y}}`$, respectively.
Then the voice conversion task can be regarded as a multi-dimensional
regression problem of learning a function from $`{\bm{x}}`$ to
$`{\bm{y}}`$. However, different from a standard regression setup,
paired training samples are not available; instead, only unpaired
samples $`\{{\bm{x}}_{i}\}_{i=1}^{n}`$ and
$`\{{\bm{y}}_{i}\}_{i=1}^{n}`$ are given.

By CDOM, we first match $`\{{\bm{x}}_{i}\}_{i=1}^{n}`$ and
$`\{{\bm{y}}_{i}\}_{i=1}^{n}`$, and then we train a multi-dimensional
kernel regression model ([Schölkopf and Smola, 2002](#bib.bib18)) using
the matched samples $`\{({\bm{x}}_{\pi(i)},{\bm{y}}_{i})\}_{i=1}^{n}`$
as

|  |  |  |
|----|----|----|
|  | $`\displaystyle\min_{{\bm{W}}}\sum_{i=1}^{n}\|{\bm{y}}_{i}-{\bm{W}}^{\top}{\bm{k}}({{\bm{x}}}_{\pi(i)})\|^{2}+\frac{\delta}{2}\textnormal{tr}({\bm{W}}^{\top}{\bm{W}}),`$ |  |

where

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle{\bm{k}}({{\bm{x}}})`$ | $`\displaystyle=(K({{\bm{x}}},{{\bm{x}}}_{{\pi}(1)}),\ldots,K({{\bm{x}}},{{\bm{x}}}_{{\pi}(n)}))^{\top},`$ |  |
|  | $`\displaystyle K({\bm{x}},{\bm{x}}^{\prime})`$ | $`\displaystyle=\exp\left(-\frac{\|{\bm{x}}-{\bm{x}}^{\prime}\|^{2}}{2\tau^{2}}\right).`$ |  |

Here, $`\tau`$ is a Gaussian kernel width and $`\delta`$ is a
regularization parameter; they are chosen by 2-fold CV.

We repeat the experiments 100 times by randomly shuffling training and
test samples, and evaluate the voice convergence performance by
*log-spectral distance* for $`8000`$ test samples¹¹ 1 The smaller the
spectral distortion is, the better the quality of voice conversion is.
([Quackenbush et al., 1988](#bib.bib15)).
Figure [4](#S5.F4 "Figure 4 ‣ 5.2 Image Matching ‣ 5 Experiments") shows
the true spectral envelope and their estimates, and
Figure [5](#S5.F5 "Figure 5 ‣ 5.3 Unpaired Voice Conversion ‣ 5 Experiments")
shows the average performance over 100 runs as the number of training
samples. These results show that the proposed LSOM tends to outperform
KS-NOCCO and KS-HSIC.

### 5.4 Photo Album Summarization

Finally, we apply the proposed LSOM method to a photo album
summarization problem, where photos are automatically aligned into a
designed frame expressed in the Cartesian coordinate system.

We use 320 images with RGB format used in [Quadrianto et al.
(2010)](#bib.bib16), which were originally extracted from *Flickr*²² 2
http://www.flickr.com. We first convert the images from RGB to Lab space
and resize them to $`40\times 40`$ pixels. Next, we convert a
$`40\times 40\times 3`$ $`(=4800)`$ image into a $`4800`$-dimensional
vector. We first consider a rectangular frame of $`16\times 20`$
$`(=320)`$, and arrange the images in this rectangular frame.
Figure [6(a)](#S5.F6.sf1 "In Figure 6 ‣ 5.3 Unpaired Voice Conversion ‣ 5 Experiments")
depicts the photo album summarization result, showing that images are
aligned in the way that images with similar colors are aligned closely.

Similarly, we use the *Frey face dataset* ([Roweis and Saul,
2000](#bib.bib17)), which consists of 225 gray-scale face images with
$`28\times 20`$ $`(=560)`$ pixels. We similarly convert a image into a
$`560`$-dimensional vector, and we set the grid size to $`15\times 15`$
$`(=225)`$. The results depicted in
Figure [6(b)](#S5.F6.sf2 "In Figure 6 ‣ 5.3 Unpaired Voice Conversion ‣ 5 Experiments")
shows that similar face images (in terms of the angle and facial
expressions) are assigned in nearby cells in the grid.

Next, we apply LSOM to the USPS dataset ([Hastie et al.,
2001](#bib.bib7)). In this experiment, we use 320 gray-scale images of
digit ‘7’ with $`16\times 16`$ $`(=256)`$ pixels. We convert an image
into a $`256`$-dimensional vector, and we set the grid size to
$`16\times 20`$ $`(=320)`$. The result depicted in
Figure [6(c)](#S5.F6.sf3 "In Figure 6 ‣ 5.3 Unpaired Voice Conversion ‣ 5 Experiments")
shows that digits with similar profiles are aligned closely.

Finally, we align the Flickr, Frey face, and USPS images into more
complex frames—a Japanese character ‘mountain’, a smiley-face shape, and
a ‘777’ digit shape. The results depicted in
Figure [7](#S5.F7 "Figure 7 ‣ 5.3 Unpaired Voice Conversion ‣ 5 Experiments")
shows that images with similar profiles are located in nearby grid
coordinate cells.

## 6 Conclusion

In this paper, we proposed two alternative methods of cross-domain
object matching (CDOM). The first method uses the dependence measure
based on the normalized cross-covariance operator, which is advantageous
over HSIC in that it is asymptotically independent of the choice of
kernels. However, with finite samples, it still depends on the choice of
kernels which needs to be manually tuned. To cope with this problem, we
proposed a more practical CDOM approach called *least-squares object
matching* (LSOM). LSOM adopts *squared-loss mutual information* as a
dependence measure, and it is estimated by the method of *least-squares
mutual information* (LSMI). A notable advantage of the LSOM method is
that it is equipped with a natural cross-validation procedure that
allows us to objectively optimize tuning parameters such as the Gaussian
kernel width and the regularization parameter in a data-dependent
fashion. We applied the proposed methods to the image matching, unpaired
voice conversion, and the photo album summarization tasks, and
experimentally showed that LSOM is the most promising.
